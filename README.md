# 🔐 Detection and Attribution of Cyber Attacks in IoT-Enabled Systems

## 📌 Project Overview

Detection and Attribution of Cyber Attacks in IoT-Enabled Systems is an academic project focused on identifying and analysing potential cyber attacks in Internet of Things (IoT) environments.

The project aims to detect suspicious network activities, assess potential security threats, and identify the source of malicious activities to improve the security and reliability of IoT-enabled systems.

## 🎯 Objectives

- Detect suspicious activities in IoT networks.
- Identify potential cyber attacks.
- Analyse attack patterns and security threats.
- Attribute potential attacks to their source devices.
- Assess attack severity and associated risks.
- Improve IoT network security and monitoring.

## ✨ Key Features

- **Attack Detection:** Identify suspicious network activities.
- **Threat Analysis:** Analyse detected security threats.
- **Attack Attribution:** Identify potential source devices.
- **Risk Assessment:** Classify threats based on risk levels.
- **Security Monitoring:** Monitor IoT-related security events.
- **Result Visualisation:** Display attack detection results.

## ⚙️ Project Workflow

1. Monitor IoT-related network activity.
2. Analyse incoming activity for suspicious patterns.
3. Detect potential cyber attacks.
4. Evaluate attack confidence and risk level.
5. Identify the potential source device.
6. Display the detection and attribution results.
