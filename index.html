About the Project

This project demonstrates a security monitoring framework designed for IoT-enabled environments. The system analyzes device behaviour and network activity to identify suspicious patterns, detect potential cyber attacks and attribute malicious activities to their possible source.

🔍 Detection

Identifies abnormal network behaviour and suspicious activities.

🧠 Classification

Classifies suspicious activities into different cyber attack categories.

🎯 Attribution

Estimates the source IP and affected IoT device associated with an attack.
